# Static Website Hosting on AWS

## Project Overview
This project demonstrates how to host a static website using Amazon S3.

## Objective
To deploy a static website on AWS without using a web server.

## Technologies Used
- HTML
- CSS
- JavaScript
- AWS S3

## AWS Services Used
- Amazon S3

## Features
- Responsive website
- Hosted on AWS
- Publicly accessible

## Deployment Steps
1. Create S3 bucket
2. Upload website files
3. Enable Static Website Hosting
4. Configure Bucket Policy
5. Access website using S3 endpoint
